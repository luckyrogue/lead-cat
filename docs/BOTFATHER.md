# BotFather setup

1. Create bot → save token → `BOT_TOKEN`
2. Description: «Кот-ассистент команды — напоминания и сценарии 🐾»
3. **Menu Button** → Web App → `WEBAPP_URL` (e.g. `https://notify.example.com`)
4. Add bot to team **group** (not only private chat)
5. Owner runs `/chatid` in group → link chat in Mini App

## Commands

| Command   | Who                         |
| --------- | --------------------------- |
| `/test`   | developer in linked group   |
| `/chatid` | developer                   |
| `/report` | developer (preview commits) |
| `/leave`  | developer                   |

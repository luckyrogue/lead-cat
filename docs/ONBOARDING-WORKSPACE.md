# Onboarding a workspace

1. Login at `/login` (email/phone code, passkey, or GitHub / GitLab)
2. **Create workspace** — name + slug
3. **Integrations** — GitHub or GitLab token + org/group → Verify
4. **Team** — add developers + VCS login mapping
5. Add platform bot to Telegram **group**
6. `/chatid` in group → **Link chat** in Mini App
7. **Scenarios** — enable presets or build chain → **Test run**
8. Dashboard — confirm next runs / last execution
